# Learning Next.js — Project 01

A beginner-friendly Next.js practice project. The project focuses on learning the fundamentals of Next.js and understanding its basic frontend concepts through a simple application.

## What I Learned

- Next.js project structure
- App Router and file-based routing
- Layouts and nested routes
- Dynamic routes
- Navigation with `next/link`
- Loading and Not Found pages
- Components and reusable UI
- Basic metadata configuration
- Tailwind CSS styling

## Tech Stack

- **Next.js**
- **React**
- **JavaScript**
- **Tailwind CSS**

## Purpose

This project is part of my ongoing journey to learn Next.js from the fundamentals and build a strong understanding of modern React and Next.js development.

> **Note:** This is a learning/practice project and is not intended to be a production application.
