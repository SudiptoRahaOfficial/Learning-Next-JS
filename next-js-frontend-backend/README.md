# Learning Next.js — Project 02

A full-stack Next.js practice project built while continuing my Next.js learning journey. This project introduces **backend development with Next.js** alongside the frontend.

## What I Learned

- Next.js App Router
- Server and Client Components
- API Routes / Route Handlers
- Backend logic with Next.js
- Handling HTTP requests and responses
- Form handling
- Connecting frontend and backend
- Server-side data handling
- Project structure and routing
- Reusable components
- Tailwind CSS

## Tech Stack

- **Next.js**
- **React**
- **JavaScript**
- **Tailwind CSS**
- **Next.js Backend / Route Handlers**
- **MongoDB**

## Purpose

This project is a part of my ongoing journey towords learning Next.js from beginner to advanced. The main goal is to understand how Next.js can be used to build **full-stack web applications**, combining frontend UI with backend functionality in a single framework.

> **Note:** This is a learning/practice project and is not intended to be a production application.
